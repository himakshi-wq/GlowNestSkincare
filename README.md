# GlowNestSkincare
GlowNest Skincare website and Google Ads campaign project


## Google Ads Campaign Project

GlowNest Skincare is a skincare website created as part of the Unified Mentor Google Ads Capstone Project.

### Website
https://glownestskincare.unaux.com/

### Project Objective
To create and practice setting up a Google Ads campaign for a skincare website.

### Campaign Type
Google Search Campaign

### Target Audience
Women interested in skincare products, hydration, acne care and affordable skincare.

### Campaign Goals
- Increase website traffic
- Reach relevant skincare audiences
- Practice Google Ads campaign setup and targeting

### Keywords
- skincare products for women
- affordable skincare
- oily skin
- acne skincare
- non-greasy skincare
- best skin care products
- skincare brands
- natural skin care
- bright skin
- The Ordinary Hyaluronic Acid 2% B5
- hydration
- hyaluronic acid 
- bright skin
- natural skin care


### Project Status
This was a practice Google Ads campaign and was not run as a live paid campaign.
